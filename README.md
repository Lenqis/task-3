# Get Unique Sorted

Функция, которая убирает дубликаты из массива чисел и возвращает отсортированный массив.

## Задача
Написать функцию `getUniqueSorted(numbers)`, которая принимает массив чисел, убирает дубликаты и возвращает массив, отсортированный по возрастанию.

## Что реализовано
- Функция `getUniqueSorted(numbers)` с одним параметром — массивом чисел.
- Удаление дубликатов через `Set` — структуру, которая хранит только уникальные значения.
- Преобразование `Set` обратно в массив через `Array.from`.
- Сортировка массива через `.sort()` с компаратором `(a, b) => a - b`.
- Возврат результата через `return`.
- Вывод результата в консоль.

## Технологии
- JavaScript (ES6+)
- Без фреймворков и библиотек.

## Как запустить
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.
3. Открыть DevTools → Console — там будет результат.

## Структура проекта
```
├── index.html   — пустая разметка для подключения скрипта
└── app.js       — массив numbers, функция getUniqueSorted, вывод результата
```
